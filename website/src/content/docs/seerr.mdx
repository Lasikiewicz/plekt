## Seerr

<ScreenshotFigure
  darkSrc="/assets/app-captures/settings-connections-seerr-dark.png"
  lightSrc="/assets/app-captures/settings-connections-seerr-light.png"
  alt="Plekt Seerr connection settings showing request integration controls"
  caption="The Seerr card configures request and availability context for media details."
/>

Connect Overseerr or Jellyseerr from [Settings → Connections](/docs/settings/connections/).

When available, detail pages show request actions for movies and shows.

Availability and request status come from Seerr; watched state remains Plekt's
responsibility.
