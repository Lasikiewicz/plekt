## Quick summary

1. Check the prerequisites below.
2. Choose your install type and start Plekt.
3. Follow the [onboarding guide](/docs/onboarding/) to claim your instance and complete Guided Setup.

Guided Setup is resumable. You can skip optional steps and return to them later.

Already running Plembfin? Follow [Upgrading from Plembfin to Plekt](/docs/upgrading-from-plembfin/)
to preserve your existing data and settings during the update.

Plekt keeps the watch archive in local SQLite and makes provider requests from the machine
where Plekt runs.

## Prerequisites

Before installing, have these ready:

- A host that can reach each media server by its configured URL.
- Persistent storage for Plekt's `/data` directory.
- A strong administrator password.
- A Plex token, Emby credentials/API key, or Jellyfin credentials/API key if you are connecting
  a media server during setup.

The browser is only the client.

A connection can look reachable from your laptop while the Plekt host cannot reach it.

Network testing must ultimately be done from the host that runs the application.
