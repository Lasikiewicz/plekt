**v1.2.0**. Use the installed version when checking which build is running after an upgrade or

the public [Changelog](/changelog/).

runtime version details out of public screenshots and issue reports when the instance is
self-hosted.

## Open the Changelog

Click the version button in the bottom-left corner of the app (for example, **v1.2.0**).
Plekt opens **Settings → Changelog**, where the installed release, newer published
releases, and available Alpha channel builds are shown. The **Check for updates** action
refreshes the release data; reading it never changes the installed version.

For the same release notes outside the app, open the [public Changelog](/changelog/). For
symptom-first help, start with [Troubleshooting](/docs/troubleshooting/).
