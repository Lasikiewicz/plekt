Logs combines server and browser diagnostic output. Use it after reproducing one small problem
so the title, source, destination, and time are easy to match with a Sync Activity row.


## Log categories


Use the category tabs to narrow the stream:

- **All Logs** shows the complete chronological stream.
- **Plex WebSockets** shows connection lifecycle and incoming Plex timeline events.
- **Outbound Sync** shows dispatches, watch writes, and manual propagation.
- **Scheduled Polls** shows periodic catch-up and scheduled sync work.
- **System Logs** shows administrative, startup, and general system events.

## Live output controls

The log view refreshes every 3 seconds. Use its controls to read without losing your place:

- **Pause updates** freezes the current snapshot; select **Resume updates** to continue. Resume
  before changing category.
- **Follow latest** keeps the newest entries in view. Scrolling up turns it off, and your
  reading position is kept while new output arrives.
- The text filter narrows the visible lines in the current category and ignores case.
- **Download Logs** exports all logs, not only the filtered lines.

## Review a problem

1. Reproduce one small problem.
2. Open Logs and select the relevant category.
3. Compare the error with the Sync Activity reason.
4. Download or preserve the relevant log before clearing it.

**Clear Logs** empties the stored diagnostic log stream. On-disk crash-forensics copies are
separate and are pruned automatically. Redact webhook URLs, credentials, and private server
names before sharing logs.
