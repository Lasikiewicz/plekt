Sync brings together timing controls, watched-state repair actions, private-list and rating sync,
cross-platform diagnostics, and the history of dispatches made by Plekt.

## Sync tuning

<ScreenshotFigure
  darkSrc="/assets/app-captures/settings-sync-tuning-dark.png"
  lightSrc="/assets/app-captures/settings-sync-tuning-light.png"
  alt="Plekt Sync Tuning settings showing watched-flag policy, playback thresholds, sync timing, and Up Next provider sync"
  caption="Sync Tuning combines watched-flag policy, playback thresholds, sync timing, and the Up Next provider-sync toggle."
/>

Tune the rules that decide when a playback event counts as watched and how resume progress is
kept:

- **Watched Threshold (%)** sets the playback percentage required to record a watch.
- **Minimum Resume Position (sec)** prevents very short pauses from becoming resume markers.
- **Active Session TTL (min)** controls when an inactive Now Playing session is considered stale.
- **Outbound Request Timeout (sec)** controls how long Plekt waits for a media-server response.
- **Fast Local-Network Sync** removes most outbound pacing delays for bulk sync operations.
  Enable it only when Plex, Emby, and Jellyfin are all self-hosted on the same trusted local
  network as Plekt. It is not safe for servers reached over the public internet.

Change one value at a time, save it, and verify the next event in Sync Activity.

## Up Next provider sync

The **Sync Up Next to media apps** toggle is on by default. When it is enabled, Plekt pushes
the unified Up Next queue to Plex Continue Watching, Emby Continue Watching, and Jellyfin Next
Up without removing anything already there. An item leaves a media app only when you clear its
progress or remove it in Plekt.

Queue additions, removals, reorderings, and resume-progress changes queue one coalesced
background push using the latest queue content. The push runs through the worker even when the
Dashboard is closed. Use the Dashboard's **Sync Up Next** action when you need an immediate
push instead of waiting for the background worker. Turn the toggle off when those provider lists
should remain unchanged; Plekt's own Up Next view remains available.

Provider feed failures retain the last successful observation and do not clear the local queue.
For the target mapping and native-rail behavior, see [Dashboard → Up Next](/docs/dashboard/#up-next).

## Manual Watch review

Select **Require review** in Sync Tuning when a media server reports **Mark Played** without a
reliable completion time. The sidebar then shows **Manual Watch review** while decisions are
pending. Provider-side watched flags are held there—even when the local item is currently
unwatched—until you confirm or dismiss them, so they cannot be propagated accidentally. The
page handles grouped episode reviews, movie reviews, date choices, provider corrections, and
the **Recheck status** action.

See the focused [Manual Watch review guide](/docs/manual-watch-review/) for the decision rules
and recovery workflow.

See [Sync Activity](/docs/sync-tools/#trakt-show-match-repair) for a separate repair path when
Trakt cannot identify a show.

## Personal Rating Sync

Personal Rating Sync is independent of watched-state synchronization and is disabled by
default. The single **Sync personal ratings** toggle enables two-way reconciliation for
personal movie, TV-show, and episode ratings across connected Plex, Emby, Jellyfin, and Trakt
accounts. Plekt remains the conflict authority: a change made directly on one service syncs
out to the others unless a local edit is genuinely newer.

The first complete snapshot imports provider ratings. Later complete snapshots reconcile
additions, edits, and removals; partial or failed reads cannot clear local ratings. Local
changes are saved first and delivered through a durable queue. The panel shows provider
status and stuck work, and **Sync now** starts an immediate pass.

Episode ratings keep their parent show and season/episode identity, even when provider leaf
IDs differ. A provider outage does not change watched state, resume progress, or the local
score.

## Plex Watchlist Sync

Plex Watchlist Sync is also independent and disabled by default. The single **Sync watchlist
with Plex** toggle keeps Plekt's local canonical movie/show Watchlist aligned with Plex's
account-level Universal Watchlist. Emby and Jellyfin are not watchlist providers.

The first run takes a safe union of the local and Plex lists. Later complete snapshots
reconcile additions and removals; outages and incomplete snapshots cannot delete local
entries. **Sync now** performs a full reconcile. Failed, unavailable, and reauthentication-
required queue work stays visible with **Retry queued changes**, and reconnecting Plex does
not roll back the local list.

The same watchlist toggle is available on the Plex card in [Settings → Media servers](/docs/settings/media-servers/)
and on the Plex step in [Onboarding](/docs/settings/tools/#reopen-onboarding).

## Sync tools

<ScreenshotFigure
  darkSrc="/assets/app-captures/settings-sync-tools-dark.png"
  lightSrc="/assets/app-captures/settings-sync-tools-light.png"
  alt="Plekt Sync Tools settings showing repair, source-of-truth, and import controls"
  caption="Sync Tools separates recent repair, local push, and additive import directions."
/>

Use these actions deliberately and keep a current backup before library-wide operations.

### Repair Recent Items

Checks recent watched items for missing or incomplete local records and repairs data that can be
resolved safely.

### Set Plekt as Source of Truth

Pushes the local canonical watched state and resume positions to one selected server or all
connected destinations. Review the preview before confirming because this can overwrite remote
state.

### Import Watched Status

Pulls watched state from one selected server or all connected destinations into Plekt. It does
not send changes out or remove remote state.

Sync Activity's **Issues only** view shows dispatches that could not reach a destination, while
the Cross-Platform Match Report shows media that a platform could not find. Open an issue for its
telemetry, verify the title identity, then retry the affected destination or use Fix Match for a
single incorrect title.

## Sync history

Sync History lists recent operations with their source, destination, outcome, and reason. Use it
to confirm that a manual action or webhook reached every intended destination; use
[Logs](/docs/settings/logs/) for the lower-level request detail.

## Recovery after an interrupted restore

An active watch-history restore pauses automated sync. Plekt automatically clears a stale
restore operation lock after an interruption so live playback tracking and watch-history
updates can resume. Check the restore result in **Settings > Backups** before retrying it.
