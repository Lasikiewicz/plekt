Settings is the administration area for connections, metadata, synchronization, backups,
diagnostics, and maintenance.

Each top-level Settings group has its own guide. Open a group below, then use the right-hand
page outline to jump between the sections on that page.


## Settings map


| Group | App path | Guide focus |
| --- | --- | --- |
| [General](/docs/settings/general/) | `/settings/general` | Account access and local instance health |
| [Media servers](/docs/settings/media-servers/) | `/settings/media-servers` | Plex, Emby, and Jellyfin connections |
| [Webhooks](/docs/settings/webhooks/) | `/settings/webhooks` | Sender setup and webhook secret handling |
| [Connections](/docs/settings/connections/) | `/settings/connections` | Trakt, Simkl, Seerr, and one-time imports |
| [Metadata](/docs/settings/metadata/) | `/settings/metadata` | Provider configuration and refresh operations |
| [Sync](/docs/settings/sync/) | `/settings/sync` | Tuning, watched-state repairs, personal rating/Watchlist sync, issues, and sync history |
| [Backup](/docs/settings/backup/) | `/settings/backup` | Local and remote backup workflows |
| [Restore](/docs/settings/restore/) | `/settings/restore` | Local and remote restore workflows |
| [Tools](/docs/settings/tools/) | `/settings/tools` | Setup, repairs, Watch-State Aliases, rebuilds, and wipe controls |
| [Users](/docs/settings/users/) | `/settings/users` | Household users, their instances, sign-in, and administrator access |
| [Logs](/docs/settings/logs/) | `/settings/logs` | Server diagnostics with pause, follow, and text filtering |
| [About](/docs/settings/about/) | `/settings/about` | Installed app details and project links |
| [Changelog](/docs/settings/changelog/) | `/settings/changelog` | In-app release history and channel builds |

Under [Tools → Watch-State Aliases](/docs/settings/tools/#watch-state-aliases), review
episode watch states stored by title or conflicting with a show's newer state. The Dismissed
list can restore entries for review. The version control opens the Changelog on **Main** for
stable installs and on **Alpha** for alpha and develop builds.

## Working in Settings

<ScreenshotFigure
  darkSrc="/assets/app-captures/settings-index-focused-dark.png"
  lightSrc="/assets/app-captures/settings-index-focused-light.png"
  alt="Plekt Settings landing page used to make and verify one configuration change"
  caption="Make one settings change at a time, wait for completion, and verify it in the affected page or Sync Activity."

Make one change at a time. Wait for the save or operation status to finish, then verify the
result in the affected app view or in [Sync Activity](/docs/sync-tools/).

For destructive maintenance and recovery actions, create a backup first and review the
operation scope before confirming it. Use [Troubleshooting](/docs/troubleshooting/) when a
setting, connection, or maintenance operation does not behave as expected.
