The Plekt sidebar is the starting point for every regular workflow. It keeps the main
pages, sync status, appearance controls, and instance actions in one consistent place.


## Main navigation

<ScreenshotFigure
  darkSrc="/assets/home-dashboard-dark.jpg"
  lightSrc="/assets/home-dashboard.jpg"
  alt="Plekt sidebar showing the main navigation pages"
  caption="The sidebar lists the primary workflows, including dedicated Watchlist, Playlists, and Ratings pages."
/>

The main sidebar links to:

- **Dashboard** for active playback, the **Up Next** queue, and recent completed TV and movie history;
- **Movies** for tracked [movie records](/docs/movies/);
- **TV Shows** for tracked [series, seasons, episodes, and progress](/docs/tv-shows/);
- **Upcoming** for [episode air dates](/docs/upcoming/);
- **Discover** for current TMDB-backed [movie and TV feeds](/docs/discover/);
- **Watchlist** for [media saved for later](/docs/watchlist/);
- **Playlists** for [ordered collections](/docs/playlists/) that can sync to Plex, Emby, or Jellyfin;
- **Ratings** for [private 1–10 scores](/docs/ratings/) across movies, shows, and episodes;
- **History** for the durable [watch-event archive](/docs/history-search/); and
- **Stats** for [reports and viewing breakdowns](/docs/stats/).

Below these, the sidebar also holds **Settings** for connections, metadata, sync tools,
backups, diagnostics, and maintenance, the **Appearance** panel, and **About**.

When a review decision is pending, the sidebar status area also links to [Manual Watch
review](/docs/manual-watch-review/). The documentation sidebar keeps **Sync Activity**,
**Manual Watch review**, and **Guides** as separate top-level paths so the review workflow is
easy to find without opening Settings first.

Select a title, poster, or history row when you need to open its media details. Discovery
cards and cards from Watchlist, Ratings, or Playlists use the same detail routes, so a
title can move between workflows without creating a duplicate library record.

## Sidebar status and actions

The sidebar can show project links, including Discord and Reddit. Use **Hide Links** to hide
the project links when you do not need them.

The lower part of the sidebar contains controls that are available across pages:

- **Complete onboarding** appears while the instance still has unfinished setup steps.
- The **Sync** indicator opens **Sync Activity**. Its status is a summary, so read the
  activity row or [Settings → Logs](/docs/settings/#logs) for the detailed reason.
- **Attention - Issue** appears when a restore or sync item needs repair; use it to open the
  grouped attention panel and follow the retry, skip, or Fix Match action.
- The app version at the bottom of the sidebar opens [Settings → Changelog](/docs/settings/changelog/)
  for the release history.

## Appearance panel

**Appearance** sits in the sidebar between Settings and About. It opens a panel with these
controls:

- **Light / Dark** changes the colour mode. The choice is saved in this browser.
- **Card Art** shows or hides artwork behind cards. **Background Art** shows or hides
  backdrop artwork on the Dashboard and detail pages. Both choices are saved in this browser.
- **Text size** (100% to 130%) scales the text on every page.
- On movie and TV detail pages, the same panel also holds the optional section switches
  for Logo Art, Cast Members, Trailers & Clips, Reviews, Images, and Related Shows.

On phones, open the navigation drawer to reach the Appearance panel. For what each switch
changes on a page, see [Appearance](/docs/appearance/).

## Page navigation

<ScreenshotFigure
  darkSrc="/assets/app-captures/settings-index-focused-dark.png"
  lightSrc="/assets/app-captures/settings-index-focused-light.png"
  alt="Plekt page navigation represented by the app's grouped settings surface"
  caption="Use the current page's section navigation and browser history to move through focused workflows."
/>

The selected sidebar item identifies the current page. On documentation pages, the
right-hand **On this page** menu jumps to sections within that page and accounts for the
sticky navigation bar.

Use the browser back button when you want to return to the previous page or detail view.

When you return to an app page, Plekt refreshes its data, starts the page at the top, and
folds any open **Posters only** card. Selecting the current sidebar item reloads that page
from the top. Live updates reconnect after the computer wakes from sleep so visible lists can
catch up with changes made while the connection was idle.
