## Simkl

Connect Simkl in [Settings → Connections](/docs/settings/connections/#simkl) using Plekt's
sign-in flow. Review the first full-sync preview before importing existing watches; later
checks can run on demand and after media-server events. Optional rating sync also supports
Simkl.
