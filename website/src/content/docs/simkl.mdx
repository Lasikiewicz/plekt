## Connect Simkl

Connect Simkl in [Settings → Connections](/docs/settings/connections/#simkl) using Plekt's
sign-in flow. Review the first full-sync preview before importing existing watches; later
checks run on demand and after media-server events. Optional rating sync and two-way dropped
title sync (shows and movies) also support Simkl. Held Simkl updates are verified automatically
every 6 hours in [Sync Activity](/docs/sync-tools/#watch-updates-on-hold), and alternate-order
shows skipped for Simkl can be reviewed episode by episode using **Review Simkl updates**.
