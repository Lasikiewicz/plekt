Trakt - Help

Website guide
  • Live Trakt Connection Keeps Trakt and Plekt in sync automatically in both directions. New watches, rewatches, and unwatches are shared across Plex, Emby, Jellyfin, and Trakt. Sync Now also checks older Trakt watches and repairs anything that has drifted out of sync.

Sync Tuning

Choose how watches are dated, when playback counts, and how quickly sync runs

Sync Tuning - Help

Website guide
  • When you manually mark an item as watched in Plex / Emby / Jellyfin Choose how app-marked watches are dated or reviewed. Require review is the default and recommended option: it holds the item for a decision in Manual Watch review, where it appears above Sync - Idle.
    • Mark as watched now - Use the time the scanner sees the watched flag.
    • Mark as watched on release day - Use the movie or episode release date.
    • Mark as watched at the same time as other episodes - Use the before/after timing from the media pages.
  • Sync historical watched items to Plex Controls whether older watched items are sent to Plex. On is recommended when you want a Plex library to match Plekt; new watches continue to sync normally either way. Off can leave older items unwatched in Plex, make Plex counts and badges differ, and keep imported or restored watches out of Plex activity.
  • Watched Threshold (%)Sets the playback percentage at which a play counts as watched. Default: 90%. Valid range: 50-100.
  • Minimum Resume Position (sec)Sets the minimum playback position saved as a resume point. Default: 60 seconds. Valid range: 0-3600.
  • Active Session TTL (min)Sets how long an inactive now-playing session remains valid. Default: 5 minutes. Valid range: 1-120.
  • Outbound Request Timeout (sec)Sets how long Plekt waits for a media server response before giving up. Default: 10 seconds. Valid range: 2-120.
  • Fast Local-Network Sync Off by default. When enabled, bulk sync operations use more concurrent requests and shorter gaps. Only enable it when Plex, Emby, and Jellyfin are all self-hosted on the same trusted local network as Plekt.
  • Sync Up Next to media apps On by default. Keeps Plekt's Up Next queue aligned with Plex Continue Watching, Emby Continue Watching, and Jellyfin Next Up. Turn it off to leave those app lists unchanged; Plekt's own Up Next view remains available.
