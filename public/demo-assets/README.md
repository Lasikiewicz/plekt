# Plekt demo assets

This directory is generated by `npm run demo:assets`. The generated catalog
and `manifest.json` are the source of truth for the bundled demo fixture.

The images and metadata are sourced from The Movie Database (TMDB) for a
non-commercial demo. The demo UI must show this attribution prominently in its
About/Credits area:

> This product uses the TMDB API but is not endorsed or certified by TMDB.

The bundle contains movie/show posters and backdrops, bundled TV season
posters, local episode stills with season-poster fallbacks, full movie/show
detail metadata, cast and review portraits, detail-gallery images, and trailer
thumbnails in `catalog.json`. See
`docs/demo-assets.md` and `manifest.json` for the exact source, selection
policy, and asset hashes.
